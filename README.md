## 📌 FarmFresh – eCommerce Platform

FarmFresh is a MERN-based eCommerce platform that connects local farmers directly with customers, ensuring fresh produce with next-day delivery.

## 🚀 Features
- Secure user authentication
- Farmer & customer dashboards
- Product listings with image uploads
- Cart and order management
- Next-day delivery system

## 🛠️ Tech Stack
**Frontend:** React.js, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Authentication:** JWT  
**Storage:** Cloudinary
